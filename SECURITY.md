# Security policy

## Reporting a vulnerability
Please **don't open a public issue** for security problems. Use GitHub's **private vulnerability reporting** (Security tab → "Report a vulnerability") on this repository. Include steps to reproduce, the impact, and the version or commit.

We aim to acknowledge reports within 3 working days and to ship a fix or mitigation for confirmed issues as quickly as we can. We'll credit you in the release notes unless you'd rather stay anonymous.

## Supported versions
Security fixes go to the latest release on `main`. Self-hosters should keep their deployment up to date.

## How Orphic is secured
See [docs/security.md](docs/security.md) for the design (invite-only access, hashed passwords and keys, per-team scoping) and the deployment checklist.
